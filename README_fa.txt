اجرای خودکار داوری روی Claude Code
==================================

این بسته همه کار را خودکار انجام می‌دهد:
  1) extract     : متن هر یافته را از PDF گزارش اودیت پیدا و جدا می‌کند
  2) adjudicate  : هر یافته را با کاتالوگ ۲۳۸ دیتکتور به Claude می‌دهد (از طریق Claude Code)
  3) report      : حکم نهایی، میزان توافق بین اجراها، و یک فایل اکسل می‌سازد

پیش‌نیاز (یک بار)
-----------------
1. پایتون ۳.۱۰ یا جدیدتر.
2. Claude Code نصب باشد. در ترمینال یک بار بزن:  claude
   وارد اکانت شو و بعد با /exit خارج شو.
3. داخل همین پوشه:
   pip install -r requirements.txt
4. همهٔ PDFها را در یک پوشه بگذار (زیرپوشه هم اشکالی ندارد).
   فهرست ۱٬۸۳۲ PDF لازم در needed_pdfs.txt است. نام فایل‌ها باید همان نام اصلی باشد.

گام ۱: اجرای آزمایشی روی ۳۰ مورد تست (حتماً اول این را بزن)
--------------------------------------------------------------
python pipeline.py all --findings findings_pilot.csv --pdf-dir "C:\path\to\pdfs" --model opus

خروجی در پوشهٔ work\findings_pilot\ ساخته می‌شود. این پوشه را zip کن و برایم بفرست
تا با بررسی دستی مقایسه کنم. شناسهٔ موارد همان T01 تا T30 است.

گام ۲: اجرای کامل روی ۵٬۱۶۹ مورد
----------------------------------
python pipeline.py all --pdf-dir "C:\path\to\pdfs" --model opus --runs 3

  --runs 3     هر یافته سه بار مستقل داوری می‌شود و حکم اکثریت گرفته می‌شود
  --workers 2  دو درخواست هم‌زمان (روی اشتراک بیشتر از ۲ توصیه نمی‌شود)
  --limit 200  فقط ۲۰۰ مورد اول (برای امتحان)

خروجی‌ها در work\findings_for_adjudication\ :
  findings_with_text.csv     متن استخراج‌شدهٔ هر یافته و وضعیت استخراج
  missing_pdfs.txt           PDFهایی که پیدا نشدند
  answers_opus.jsonl         جواب کامل هر اجرا
  results_opus.xlsx          جدول نهایی (حکم، توافق، مکانیزم، شدت، ...)
  results_opus_summary.txt   خلاصهٔ آمار

نکته‌ها
-------
- اگر وسط کار قطع شد (یا کامپیوتر خاموش شد)، همان دستور را دوباره بزن. کارهای انجام‌شده تکرار نمی‌شوند.
- وقتی سقف مصرف اشتراک پر شود، اسکریپت خودش ۱۵ دقیقه صبر می‌کند و ادامه می‌دهد.
- اجرای کامل با سه بار تکرار حدود ۱۵ هزار درخواست است و روی اشتراک احتمالاً چند روز طول می‌کشد.
- نسخهٔ دقیق مدلی که واقعاً استفاده شده در خلاصهٔ نهایی ثبت می‌شود؛ همین را در مقاله گزارش کن.
- ستون excerpt_relevant نشان می‌دهد متن استخراج‌شده واقعاً مربوط به همان یافته بوده یا نه.
